# AI Resume Analyzer

An AI-powered Resume Analyzer built using Flask and Python.

## Features

- User Registration & Login
- Resume PDF Upload
- PDF Text Extraction
- Skill Detection
- Career Recommendation
- Missing Skills Analysis
- Resume Score Calculation
- Bootstrap UI

## Technologies Used

- Python
- Flask
- SQLite
- SQLAlchemy
- HTML
- CSS
- Bootstrap
- PyPDF2

## How It Works

1. User uploads resume
2. System extracts text from PDF
3. Skills are detected
4. Career suggestions are generated
5. Missing skills are identified
6. Resume score is calculated
